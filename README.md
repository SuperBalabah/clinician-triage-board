# 臨床通訊分流系統 (生醫電資競賽提案與 Demo 說明書)

## 1. 核心定位與設計哲學
專為臨床醫師打造的**極簡、無壓力、情境感知之臨床通訊分流工具**。
* **零多餘資訊**：移除所有多餘標籤與冗贅引導字，維持極致簡潔與操作直覺。
* **非嚴肅稽核，事畢即銷案**：非醫療過失存證系統，處理完畢一鍵完成滑離。

---

## 2. 系統架構與運作規範 (Specification)

### A. 通訊分流與鈴聲規範 (Triage Logic)
* 🚨 **急 Call**：
  * **臨床定義**：重大危急事件（急救、術後大出血、休克、急刀）。
  * **特性**：全院專屬統一強制鈴聲，直接語音連線，**不經任何表單架構**。
* 📞 **一般 Call**：
  * **臨床定義**：急迫但非致命討論。
  * **特性**：醫師自訂常規鈴聲，直接語音連線，**不經任何表單架構**。
* 💬 **留言板**：
  * **臨床定義**：非同步病情通報或照會。
  * **特性**：附帶期望回覆時限（15分鐘 / 1小時 / 4小時 / 當班），依時限倒數自動排序，採用語音 AI 結構化 ISBAR。

### B. 手機桌面 Widget 交互機制
* **極簡免切換按鈕**：
  * **短按 (Tap)**：自動在已啟用的狀態清單中循環跳轉（如：上刀中 $\rightarrow$ 查房中 $\rightarrow$ 門診中 $\rightarrow$ 上刀中）。
  * **長按 (Press & Hold)**：彈出快速狀態選擇盤，供精準直接選取。
* **顯示資訊**：當前情境 + 括號偏好（例如 `上刀中 (盡量留言)`）及最急迫待覆留言快覽。

### C. 醫護人員個人檔案與偏好 (Clinician Profile)
* 在系統中點擊任何醫護姓名標籤（如 `王大明 急診R`），即時彈出個人檔案：
  * 基本身分（科部、職稱、員工編號）。
  * 當前臨床情境與對應通訊偏好。
  * **個人附註**：由醫護在設定頁自訂（例如：`休息時有事請找第一線值班 / 11/25-11/30 年休`）。

### D. App 設定區 (Settings)
* **小工具狀態庫管理**：勾選哪些狀態要加入 Widget 短按輪跳，並自訂各狀態之偏好通訊模式。
* **看板顯示偏好**：切換「預設只顯示請求」或「顯示請求 + 現況」，不佔用看板視覺空間。
* **我的個人附註維護**：編輯自我簡介與臨床備註。

### E. 雙向追蹤與計數動態聯動
* 雙頁籤即時連動：`待回覆 (N)` 與 `已傳送 (N回覆)`。
* 點擊「完成」或「撤銷」時，待辦與發送計數自動增減。
* **已傳送區塊**：
  * 點擊任何已傳送訊息（包含已獲回覆者），均可展開詳細 ISBAR 原始內容。
  * 未獲回覆之項目，發送方享有「撤銷」按鈕以取消通報。

### F. 通話情境標註 (Context Linking)
* 通話畫面頂部清晰標註：
  * 回電情境：**`回覆留言：302床 張O美 (針對：請求評估是否急送刀房止血)`**。
  * 主動通話：**`主動通話`**。
